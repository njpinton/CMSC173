================================================================================

Frame 5: "The Perceptron: Building Block of Neural Networks"
- TikZ Diagram: Input neurons → Summation → Activation → Output
- Mathematical Model: z = sum(w_i * x_i) + b, then y = σ(z)
- Components: Inputs (x_1, x_2, x_3), weights (w_1, w_2, w_3), bias (b)
- Activation function: σ (sigmoid or other non-linear function)
- No file figures (contains TikZ diagrams)

Frame 6: "Neural Network Components and Architecture"
- Two-column comparison:
  Left: Single Processing Unit (neuron with inputs, weights, activation)
  Right: Multi-Layer Perceptron (4 input → 5 hidden → 3 hidden → 1 output)
- Processing Unit: Inputs D, weights D, bias, activation function σ
- Multi-Layer: Fully connected layers with forward propagation arrows
- Key Concepts: Processing units compute z then y = σ(z)
- No file figures (TikZ network diagrams)

Frame 7: "Perceptron: Mathematical Formulation"
- Complete Mathematical Description:
  z = Σ w_i * x_i + b = w^T * x + b
  y = σ(z) = σ(w^T * x + b)
- Variables: x (input vector), w (weight vector), b (bias), σ (activation)
- Two activation functions:
  Step Function (original): Binary output, not differentiable
  Sigmoid (modern): 1/(1+e^-z), smooth and differentiable
- Problem with step function: Not amenable to gradient-based learning

Frame 8: "Perceptron Learning Algorithm"
- Two-column comparison:
  Left: Original Perceptron Rule (update on misclassification)
  Right: Gradient Descent (modern approach)
- Original: w_j := w_j + α(y_i - y_hat_i)x_ij
- Convergence guaranteed for linearly separable data
- Gradient Descent: Loss = (1/2)(y - y_hat)^2
- Weight updates via gradient: w_j := w_j - α * ∂L/∂w_j
- Limitation: Single perceptron only learns linearly separable functions
- Solution: Multi-layer networks!

SECTION 3: ACTIVATION FUNCTIONS (Frames 9-13)
================================================================================

Frame 9: "Activation Functions: The Heart of Non-linearity"
- Figure: ../figures/activation_functions.png (curves of various functions)
- Purpose: Introduce non-linearity to enable complex pattern learning
- Without activation: Stacked linear operations → still linear
- With activation: Network gains universal approximation capability

Frame 10: "Activation Functions: Mathematical Properties"
- Two-column comparison:
  Left: Sigmoid: σ(x) = 1/(1+e^-x)
    Range: (0,1), Smooth, Interpretable as probability
    Derivative: σ'(x) = σ(x)(1-σ(x))
    Issues: Vanishing gradients for large |x|
  Right: Hyperbolic Tangent: tanh(x) = (e^x - e^-x)/(e^x + e^-x)
    Range: (-1,1), Zero-centered output, Steeper gradients
    Derivative: tanh'(x) = 1 - tanh^2(x)
    Advantage: Better than sigmoid overall

Frame 11: "Activation Functions: ReLU Family"
- Two-column comparison:
  Left: ReLU (Rectified Linear Unit): max(0, x)
    Advantages: Computationally efficient, no vanishing for x>0, sparse activation
    Most popular choice for hidden layers
    Derivative: 1 if x>0, else 0
  Right: Leaky ReLU: x if x>0, else αx (typically α=0.01)
    Advantages: Avoids "dying ReLU" problem, gradient for negatives
    Derivative: 1 if x>0, else α
- Dying ReLU Problem: Neurons get stuck outputting zero

Frame 12: "Activation Function Derivatives"
- Figure: ../figures/activation_derivatives.png (derivative curves)
- Why Derivatives Matter: Crucial for backpropagation
- Derivatives determine how errors flow backward during training
- Different activations have different gradient properties
- Affects training speed and stability

Frame 13: "Choosing Activation Functions"
- Two-column comparison:
  Left: Guidelines for selection
    Hidden Layers: ReLU (default), Leaky ReLU, Tanh (zero-centered), avoid Sigmoid
    Output Layer: Sigmoid (binary classification), Softmax (multi-class), Linear (regression), Tanh (bounded regression)
  Right: Common Issues
    Vanishing Gradients: Sigmoid/Tanh derivatives → 0, deep networks suffer
    Dying ReLU: Neurons stuck at zero, no gradient flow
- Best Practice: Start with ReLU for hidden layers, choose output activation based on task

Frame 15: "Network Architecture: Mathematical Representation"
- Mathematical formulation for L-layer network:
  a^(0) = x (input)
  z^(l) = W^(l) * a^(l-1) + b^(l) (pre-activation)
  a^(l) = σ^(l)(z^(l)) (post-activation)
  y_hat = a^(L) (output)
- Variables explained: W^(l) weight matrix, b^(l) bias vector, n_l neurons in layer l, σ^(l) activation for layer l
- Recursive structure: Each layer depends on previous layer's output

- Two-column comparison:
  Left: Matrix Dimensions
    Input: a^(l-1) shape (n_{l-1}, 1)
    Weights: W^(l) shape (n_l, n_{l-1})
    Output: a^(l) shape (n_l, 1)
    Batch: A^(l) shape (n_l, m) for m examples
  Right: Parameter Count
    Total: Σ(n_l × n_{l-1} + n_l) across all layers
    Example: 784→128→64→10 = 109,386 parameters
    Memory scales with: Depth, layer width, batch size
- Memory considerations for practical networks

Frame 17: "Network Design Considerations"
- Two-column comparison:
  Left: Depth vs Width Trade-off
    Deeper Networks: More layers, better hierarchies, complex functions, risk of vanishing gradients
    Wider Networks: Fewer layers, more neurons, easier training, risk of overfitting
  Right: Architecture Guidelines
    Hidden Layer Size: Start with 1-2 hidden layers
    Size rule: Between input/output dimensions, or √(n_in × n_out)
    Number of Layers: Simple: 1-2, Complex: 3+, Very deep: special techniques
- Best Practice: Start simple, increase complexity gradually using validation performance

================================================================================

Frame 18: "Forward Propagation: Information Flow"
- TikZ Diagram: 3-layer network (3 inputs → 2 hidden → 1 output)
- Input neurons: x_1, x_2, x_3
- Hidden neurons: h_1, h_2
- Output neuron: y
- Computation boxes: z^(1) and z^(2) shown
- Activation boxes: σ shown for each layer
- Formulas: z^(1) = W^(1)x + b^(1), z^(2) = W^(2)a^(1) + b^(2)
- Forward Flow arrows showing left-to-right propagation
- Key Insight: Information flows input→output, layer by layer, for predictions

Frame 19: "Forward Propagation Algorithm"
- Algorithm pseudocode:
  Input: x, weights {W^(l)}, biases {b^(l)}
  Initialize a^(0) = x
  For each layer l=1 to L:
    Compute z^(l) = W^(l) * a^(l-1) + b^(l)
    Apply activation: a^(l) = σ^(l)(z^(l))
  Output: y_hat = a^(L)
- Two implementation variations:
  Left: Vectorized Implementation (batch processing)
    Z^(l) = A^(l-1) * (W^(l))^T + b^(l)
    A^(l) = σ^(l)(Z^(l))
    Complexity: O(L·N·M) where L=layers, N=max neurons, M=batch size
  Right: Example Calculation
    Network: 2→3→1, Input: [0.5, 0.8]^T
    Forward pass through both layers

Frame 20: "Forward Propagation: Implementation Details"
- Two-column comparison:
  Left: Memory Considerations
    Storage: Save all activations a^(l) and pre-activations z^(l)
    Needed for backpropagation
    Memory: Σ n_l × batch_size across all layers
    Trade-offs: Larger batches→more memory/better GPU, smaller→less memory/noisier gradients
  Right: Numerical Stability
    Common Issues: Overflow (large values), Underflow (→0), NaN propagation
    Solutions: Gradient clipping, log-sum-exp trick, careful dtype selection
- Numerical stability critical for deep networks

Frame 21: "Forward Pass: Handworked Example"
- Two-column comparison:
  Left: Step 1 - Input Layer to Hidden
    Network weights (example): W^(1) = [[0.5, 0.3], [0.2, 0.4]], b^(1) = [0.1, 0.05]
    Input: x = [0.5, 0.8]^T
    Computation: z^(1) = W^(1)*x + b^(1) = [0.52, 0.43]^T
  Right: Step 2 & 3 - Hidden to Output
    z^(1) = [0.52, 0.43]^T → Apply sigmoid
    a^(1) = [0.627, 0.606]^T
    Output layer: W^(2) = [0.6, 0.5], b^(2) = 0.3
    z^(2) = 0.979 → Apply sigmoid
    y_hat = 0.727
- Step-by-step numerical calculation through network

Frame 22: "Forward Pass: Handworked Example (continued)"
- Continuation of example from Frame 21
- Detailed intermediate calculations:
  a^(1)_1 = σ(0.52) = 0.627
  a^(1)_2 = σ(0.43) = 0.606
  z^(2) = 0.6×0.627 + 0.5×0.606 + 0.3 = 0.979
  y_hat = σ(0.979) = 0.727
- All intermediate values stored for backpropagation
- Summary: Input [0.5, 0.8] → Hidden [0.627, 0.606] → Output 0.727

SECTION 6: BACKPROPAGATION ALGORITHM (Frames 23-28)
================================================================================

Frame 23: "Backpropagation: Error Flow"
- TikZ Diagram: Same network as Frame 18, but showing backward flow
- Forward connections shown faint (light opacity)
- Red error arrows shown going backward through network
- Loss function L connected to output
- Gradient computations: δ^(2), δ^(1) boxes shown
- Chain rule arrows showing error propagation direction
- Gradient formulas: ∂L/∂W^(1) = δ^(1) * x^T, etc.
- Key Concept: Backpropagation is efficient algorithm using chain rule
- No file figures (TikZ network with error flow)

Frame 24: "Mathematical Foundation: Chain Rule"
- Goal: Compute ∂L/∂W^(l) and ∂L/∂b^(l) for all layers
- Chain Rule Application:
  ∂L/∂W^(l) = (∂L/∂z^(l)) * (∂z^(l)/∂W^(l))
  ∂L/∂b^(l) = (∂L/∂z^(l)) * (∂z^(l)/∂b^(l))
  ∂L/∂a^(l-1) = (∂L/∂z^(l)) * (∂z^(l)/∂a^(l-1))
- Key Insight: Define error terms δ^(l) = ∂L/∂z^(l)
- Two-column derivations:
  Left: Gradient Computations
    ∂L/∂W^(l) = δ^(l) * (a^(l-1))^T
    ∂L/∂b^(l) = δ^(l)
    δ^(l-1) = (W^(l))^T * δ^(l) ⊙ σ'(z^(l-1))
  Right: Output Layer
    δ^(L) = ∂L/∂a^(L) ⊙ σ'(z^(L))
    Common case (MSE + sigmoid): δ^(L) = (a^(L) - y) ⊙ a^(L) ⊙ (1 - a^(L))

Frame 25: "Backpropagation Algorithm"
- Detailed algorithm pseudocode:
  Input: Training pair (x, y), network weights
  Step 1: Forward Pass - compute all a^(l) and z^(l) [STORE THEM!]
  Step 2: Compute Output Error - δ^(L) = ∂L/∂a^(L) ⊙ σ'(z^(L))
  Step 3: Propagate Error - for l=L-1 down to 1: δ^(l) = (W^(l+1))^T * δ^(l+1) ⊙ σ'(z^(l))
  Step 4: Compute Gradients - ∂L/∂W^(l) = δ^(l) * (a^(l-1))^T, ∂L/∂b^(l) = δ^(l)
- Two-column analysis:
  Left: Computational Complexity
    Time: O(number of weights) - same as forward pass
    Space: O(network size) - must store all activations
    Memory scales with depth
  Right: Why Backpropagation Works
    Efficiency: Reuses computations via chain rule
    Automatic: No manual gradient derivation needed
    Exact: Computes exact gradients (not approximations)
    General: Works for any differentiable network
    Historical: Rumelhart, Hinton, Williams (1986) - made deep learning practical

Frame 26: "Computational Graph Perspective"
- TikZ Diagram: Computational graph for y = σ(wx + b)
- Input nodes: x (input), w (weight)
- Operation nodes: × (multiply), + (add), σ (sigmoid)
- Intermediate: z_1 = wx, z_2 = wx + b
- Output: y = σ(z_2)
- Loss function L connected to output
- Forward arrows (blue): x,w → × → + → σ → y → L
- Backward arrows (red dashed): Gradient flow backward
- Gradient labels: ∂L/∂y, ∂L/∂z_2, ∂L/∂z_1, ∂L/∂w, ∂L/∂b
- Modern View: Backprop is automatic differentiation on computational graphs
- Modern frameworks (TensorFlow, PyTorch) build graphs automatically

Frame 27: "4-Layer Neural Network: Differential Equation Derivation"
- Network Structure: Input → Hidden1 → Hidden2 → Hidden3 → Output (4 hidden layers total)
- Forward Pass Equations (all 4 layers):
  a^(0) = x (input)
  z^(1) = W^(1)*a^(0) + b^(1), a^(1) = σ(z^(1))
  z^(2) = W^(2)*a^(1) + b^(2), a^(2) = σ(z^(2))
  z^(3) = W^(3)*a^(2) + b^(3), a^(3) = σ(z^(3))
  z^(4) = W^(4)*a^(3) + b^(4), a^(4) = σ(z^(4)) (output)
- Loss Function: L = (1/2)||a^(4) - y||^2
- Two-column analysis:
  Left: Output Layer Error
    δ^(4) = (a^(4) - y) ⊙ σ'(z^(4))
  Right: Chain Rule for Hidden Layers
    δ^(l) = (W^(l+1))^T * δ^(l+1) ⊙ σ'(z^(l)) for l=3,2,1
- Detailed derivation for deep network training

Frame 28: "4-Layer Network: Complete Backpropagation Derivation"
- Step-by-Step Gradient Computation:
- Two-column analysis:
  Left: Error Propagation (all layers)
    Layer 4 (output): δ^(4) = (a^(4) - y) ⊙ σ'(z^(4))
    Layer 3: δ^(3) = (W^(4))^T * δ^(4) ⊙ σ'(z^(3))
    Layer 2: δ^(2) = (W^(3))^T * δ^(3) ⊙ σ'(z^(2))
    Layer 1: δ^(1) = (W^(2))^T * δ^(2) ⊙ σ'(z^(1))
  Right: Weight and Bias Gradients
    For each layer l=1,2,3,4:
    ∂L/∂W^(l) = δ^(l) * (a^(l-1))^T
    ∂L/∂b^(l) = δ^(l)
    Update: W^(l) := W^(l) - α * ∂L/∂W^(l), b^(l) := b^(l) - α * ∂L/∂b^(l)
- Key Insight: Error flows backward, each layer's error depends on next layer times weight transpose

Frame 31: "L1 and L2 Regularization"
- Add penalty terms to loss function for model complexity control
- Two-column comparison:
  Left: L2 Regularization (Ridge)
    L_total = L_data + λ * Σ||W^(l)||_2^2
    ||W^(l)||_2^2 = Σ_i Σ_j (W_ij^(l))^2
    Effect: Shrinks weights toward zero, uniform penalty, smooth distributions
    Preferred for most applications
    Gradient: ∂L_total/∂W^(l) = ∂L_data/∂W^(l) + 2λ*W^(l)
  Right: L1 Regularization (Lasso)
    L_total = L_data + λ * Σ||W^(l)||_1
    ||W^(l)||_1 = Σ_i Σ_j |W_ij^(l)|
    Effect: Promotes sparsity, automatic feature selection, sparse networks
    Useful for interpretability
    Gradient: ∂L_total/∂W^(l) = ∂L_data/∂W^(l) + λ*sign(W^(l))
- Hyperparameter λ controls regularization strength

Frame 32: "L1 vs L2 Regularization Comparison"
- Figure: ../figures/l1_vs_l2_regularization.png
- Shows geometry of L1 vs L2 constraint regions
- Two-column comparison:
  Left: When to Use L2
    General-purpose regularization
    All features potentially relevant
    Want smooth weight shrinkage
    Most common choice
  Right: When to Use L1
    Feature selection needed
    Many irrelevant features
    Want sparse models
    Interpretability important
- Figure shows L1 creates sparse solutions (axes), L2 smooth shrinkage

Frame 33: "Dropout: A Different Approach"
- TikZ Diagram: Side-by-side comparison of training vs testing
- Training (left): Input → Hidden (some neurons marked X for dropout) → Output
- Testing (right): Input → Hidden (all neurons active) → Output
- Dropout rate: p=0.5 shown
- At test time: All neurons active
- Technique: Randomly set neurons to zero during training
- Prevents co-adaptation and improves generalization

Frame 34: "Dropout: Mathematical Formulation"
- Training Phase:
  r^(l) ~ Bernoulli(p) (dropout mask)
  ã^(l) = r^(l) ⊙ a^(l) (apply mask)
  z^(l+1) = W^(l+1) * ã^(l) + b^(l+1)
- Testing Phase:
  z^(l+1) = p * W^(l+1) * a^(l) + b^(l+1) (scale weights)
- Two-column analysis:
  Left: Dropout Benefits
    Prevents overfitting via co-adaptation reduction
    Model averaging: Ensemble of networks effect
    Robust features: Redundant representations
    Easy to implement: Simple forward pass modification
    Typical rates: 0.2-0.5 for hidden, 0.1-0.2 for input
  Right: Implementation Notes
    Training: Randomly drop neurons
    Testing: All neurons but scaled outputs
    Modern frameworks handle automatically
    Why scaling works: Expected activation levels maintained
    Training: Neuron "on" with probability p
    Testing: All "on", so scale by p to match

SECTION 8: TRAINING BEST PRACTICES (Frames 37-40)
================================================================================

Frame 37: "Weight Initialization"
- Proper initialization crucial for successful training
- Two-column comparison:
  Left: Poor Initialization
    All zeros: No learning (complete symmetry)
    Too large: Exploding gradients, saturation
    Too small: Vanishing gradients, weak signals
  Right: Good Initialization
    Xavier/Glorot (for Sigmoid/Tanh): W_ij ~ N(0, √(2/(n_in + n_out)))
    He initialization (for ReLU): W_ij ~ N(0, √(2/n_in))
    Bias initialization: b_i = 0 (usually sufficient)
- Why These Work: Maintain activation variance and gradient variance across layers
- Critical for deep network training

Frame 38: "Learning Rate and Optimization"
- Two-column comparison:
  Left: Learning Rate Selection
    Too high: Overshooting, instability, loss explodes/oscillates
    Too low: Slow convergence, stuck in local minima, poor performance
    Good range: Typically 10^-4 to 10^-1
  Right: Advanced Optimizers
    SGD with Momentum: v_t = β*v_{t-1} + (1-β)*∇L, W := W - α*v_t
    Adam (Adaptive Moments):
      m_t = β_1*m_{t-1} + (1-β_1)*∇L (first moment)
      v_t = β_2*v_{t-1} + (1-β_2)*(∇L)^2 (second moment)
      W := W - α * m_t/(√v_t + ε)
    Default choice: Adam with α=0.001
- Learning Rate Scheduling: Decay strategies (step, exponential, cosine), start high, reduce during training

Frame 39: "Training Diagnostics"
- Monitor these metrics during training
- Three-column analysis:
  Left: Loss Monitoring
    Training loss: Should decrease monotonically
    Validation loss: Should decrease then stabilize
    Gap: Large gap indicates overfitting
    Warning signs: Loss increases (LR too high), plateaus early (LR too low), validation increases (overfitting)
  Center: Gradient Monitoring
    Gradient norms: Should be reasonable (10^-6 to 10^-1)
    Vanishing: Gradients → 0 in early layers
    Exploding: Gradients become very large
  Right: Activation & Weight Monitoring
    Activation statistics: Mean, std, sparsity
    Dead neurons: Always output zero
    Saturated neurons: Always in saturation
    Healthy: Reasonable variance, some sparsity, no dead layers
    Weight distributions: Should be reasonable
    Weight updates: |ΔW|/|W| ≈ 10^-3
- Tools: TensorBoard, Weights & Biases for monitoring

Frame 40: "Common Problems and Solutions"
- Four problem blocks:
  Problem 1: Vanishing Gradients
    Symptoms: Early layers don't learn, gradients → 0
    Solutions: Use ReLU, proper initialization, batch normalization
  Problem 2: Overfitting
    Symptoms: Training >> validation accuracy, validation loss increases
    Solutions: Add regularization (L2, dropout), reduce complexity, more data
  Problem 3: Exploding Gradients
    Symptoms: Loss becomes NaN, weights blow up
    Solutions: Gradient clipping, lower learning rate, better initialization
  Problem 4: Slow Convergence
    Symptoms: Loss decreases slowly, stuck in plateaus
    Solutions: Increase learning rate, use adaptive optimizers (Adam)
